
# Clinical SAS Practice Portfolio

Hands-on clinical SAS programming portfolio: Base SAS, SQL, and CDISC SDTM and ADaM datasets, built on clinical trial practice data, with R and pharmaverse versions to follow.

## About
I'm a pharmacy graduate working in clinical data and building hands-on skills in clinical programming. This repository tracks my learning in public.

## Focus areas
- Base SAS and Proc SQL
- CDISC SDTM and ADaM datasets
- End-to-end clinical data flow, from raw data to analysis outputs
- R and pharmaverse versions, coming later

## Data
Only publicly available practice or synthetic data is used here. No real patient data and no employer data.

## Status
Work in progress. Updated regularly.

## Goal
A complete portfolio taking practice trial data from raw, to SDTM, to ADaM, to tables and figures.
